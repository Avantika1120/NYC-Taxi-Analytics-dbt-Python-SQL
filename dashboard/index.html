Key Business Insights

What a recruiter/interviewer should notice

Peak demand is concentratedLate afternoon and evening windows drive the highest trip volume, supporting targeted driver-allocation decisions.
Airport trips are economically differentAirport rides have a materially higher average ticket and should be analyzed separately from standard city trips.
Revenue is geographically concentratedA relatively small set of Manhattan and airport-adjacent zones contribute a disproportionate share of trip revenue.

Architecture & dbt Lineage

How raw public data becomes decision-ready analytics

NYC TLC Parquet + Zone Lookup ↓ Python ingestion / validation ↓ DuckDB raw schema ↓ dbt staging ├─ stg_yellow_trips └─ stg_taxi_zones ↓ dbt intermediate └─ int_trips_enriched ↓ Fact + Dimension + Marts ├─ fct_trips (incremental) ├─ dim_zones ├─ mart_daily_kpis ├─ mart_zone_performance └─ mart_hourly_demand ↓ SQL analysis + Dashboard
Note: This standalone HTML page is a visual portfolio demo with representative values so it can be opened directly from GitHub. The repository's Python + dbt pipeline computes the real warehouse-backed metrics, and the Streamlit app reads from those modeled tables for live analysis.
